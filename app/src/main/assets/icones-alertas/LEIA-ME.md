# Ícones personalizados dos canais de alerta

Coloque PNGs quadrados nesta pasta antes de compilar: planetas.png, regioes.png, noticias.png, ordem-maior.png e dss.png.

Sugestão: 256 × 256 ou 512 × 512, arte centralizada, fundo transparente e pouca margem interna. Cada imagem preenche uma moldura de 34 dp, com cantos arredondados. Evite textos pequenos.

Os ícones vetoriais incluídos aparecem automaticamente enquanto esses arquivos não existirem ou se uma imagem não carregar. Nenhum arquivo personalizado existente é removido pelo patch.
